# Mine Master

Mine Master is a polished, responsive website for a multi-skill Minecraft practice world. It presents six training disciplines, searchable difficulty filters, randomized drills, a practice timer, personal-best tracking, and theme controls.

## Technology

- Semantic HTML5
- Responsive CSS3
- Vanilla JavaScript
- Browser `localStorage` for theme and personal-best preferences

## Run locally

No installation or build step is required. Open `index.html` in a browser, or serve the folder with any static file server.

Before release, replace the clearly marked `#download-placeholder` link in `index.html` with the real world download URL. Community buttons intentionally remain placeholders until official URLs are supplied.
